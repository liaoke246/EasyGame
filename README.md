# 苔原谷 · Mossfield

一个轻量的多人在线俯视角像素游戏原型。玩家以访客身份进入后，会获得随机旅人编号和角色，可以在同一张地图中移动、共同对抗随机出现的僵尸。

## 已实现

- 匿名进入、随机且持久化的旅人编号与角色
- 俯视角像素地图、八方向移动/射击和地图碰撞
- WebSocket 多人位置与状态同步
- 服务端权威移动、攻击、受伤、击倒和复活
- 随机刷新的行者、疾行者和巨尸，自动追踪并攻击玩家
- 冲锋枪、喷子和火箭筒三种无限弹药武器
- 精细俯视像素贴图角色、僵尸、武器与逐帧爆炸动画
- 与角色统一画风的森林地面、道路、建筑、树木、池塘和场景装饰
- 角色与三类僵尸分别拥有上、下、左、右四方向完整步态循环
- 固定角色身高与脚底锚点、距离驱动步频、落脚尘土和仅作用于武器的后坐反馈
- 人物本体与武器/手臂分层；移动、射击和切枪始终保留同一人物模型
- 客户端即时移动、服务端柔和纠偏，以及起步、停步和反向转身加速度
- 扩展为 2560 × 1440 的地图，并提升服务端 Tick 与快照频率
- 三把武器逐方向测量枪口像素，八向旋转、枪火、弹道和服务端命中共用同一变换
- 火箭弹服务端实体飞行，命中僵尸、障碍物或达到射程后才结算爆炸伤害
- 客户端移动预测、远端平滑和实时延迟/丢包显示
- 分层枪口火光、烟雾、弹壳、发光弹道、命中碎片和逐帧爆炸效果
- 真实资源加载进度与 WebP 运行时图集，首屏游戏素材体积减少约 80%
- 玩家血量、在线人数、击倒数和事件提示
- 键盘与移动端触摸操作
- 生产环境下由游戏服务器直接提供前端文件

## 本地运行

需要 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。可以打开两个浏览器窗口测试联机。

使用 `WASD` 或方向键移动，按住空格射击，按 `1`、`2`、`3` 切换武器。

## 生产构建

```bash
npm run build
npm start
```

构建完成后访问 `http://localhost:3001`。

## 自动部署

推送到 `main` 分支后，GitHub Actions 会构建、运行联机检查，并通过 SSH
发布到生产服务器。工作流需要以下 GitHub Environment Secrets：

- `SERVER_HOST`
- `SERVER_PORT`
- `SERVER_USER`
- `SERVER_SSH_KEY`
- `SERVER_HOST_KEY`

服务器由 systemd 运行 Node.js 进程，并通过支持 WebSocket 的 Nginx 反向代理
对外提供游戏。部署脚本会在健康检查失败时自动切回上一个版本。

## 自动化联机检查

```bash
npm run build
npm run test:animation
npm run test:smoke
```

动画测试会锁定人物/武器分层、八向瞄准变换和枪口像素锚点；联机测试会启动临时
服务器，连接两个玩家并验证同步、僵尸朝向、三把武器和 45 度射击。

## 项目结构

```text
client/  Phaser + TypeScript + Vite 游戏客户端
shared/  客户端与服务器共用的方向、武器和枪口规则
server/  Express + Socket.IO 权威游戏服务器
scripts/ 本地验证脚本
```

玩家身份目前保存在 `server/data/players.json`。这是适合初版的本地存储；正式上线时可以替换为 Supabase Auth 和 PostgreSQL。
