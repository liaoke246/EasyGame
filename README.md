# 方块危机 · Block Crisis

一个轻量的多人在线俯视角僵尸生存游戏。玩家以访客身份进入方块竞技场，获得随机编号和角色，与其他玩家共同对抗不断刷新的尸潮。

## 已实现

- 匿名进入、随机且持久化的旅人编号与角色
- 俯视角像素地图、八方向移动/射击和地图碰撞
- WebSocket 多人位置与状态同步
- 服务端权威移动、攻击、受伤、击倒和复活
- 随机刷新的行者、疾行者和巨尸，自动追踪并攻击玩家
- 冲锋枪、喷子和火箭筒三种无限弹药武器
- 带顶面、正面、暗侧面和方向遮挡的程序化伪 3D 方块角色与三类僵尸
- 统一的双色竞技场、高墙、圆桶、红色补给箱、血迹、火箭和爆炸特效
- 连续距离驱动的八方向步态，玩家和僵尸始终保持固定模型尺寸
- 身体、短肢体与唯一武器层组合；移动、射击和切枪不会替换人物模型
- 客户端即时移动、服务端柔和纠偏，以及起步、停步和反向转身加速度
- 扩展为 3840 × 2160 的地图，并提升服务端 Tick 与快照频率
- 三把武器的八向枪管、枪火、弹道和服务端命中共用同一枪口变换
- 火箭弹服务端实体飞行，命中僵尸、障碍物或达到射程后才结算爆炸伤害
- 客户端移动预测、远端平滑和实时延迟/丢包显示
- 分层枪口火光、烟雾、弹壳、发光弹道、命中碎片和方块爆炸效果
- 角色、僵尸和地图无需运行时贴图下载，进入速度更快
- 玩家血量、在线人数、击倒数和事件提示
- 玩家每次出生或复活时有 12% 概率变为乌萨奇兔子外观
- 持久化随机英文代号，以及所有玩家和僵尸头顶的世界空间血条
- 3840 × 2160 扩展地图、场景碰撞内缩和与可见模型一致的角色命中半径
- 枪弹从权威枪口射出、命中圆形身体边界并会被房屋、树木等障碍阻挡
- 短段高速曳光、命中火花和带网络外推的平滑火箭轨迹
- 键盘操作，以及手机双摇杆操作（左侧移动、右侧八方向瞄准/射击、三键切换武器）
- 生产环境下由游戏服务器直接提供前端文件

## 本地运行

需要 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。可以打开两个浏览器窗口测试联机。

使用 `WASD` 或方向键移动，按住空格射击，按 `1`、`2`、`3` 切换武器。

## 生产构建

```bash
npm run build
npm start
```

构建完成后访问 `http://localhost:3001`。

## 自动部署

推送到 `main` 分支后，GitHub Actions 会构建、运行联机检查，并通过 SSH
发布到生产服务器。工作流需要以下 GitHub Environment Secrets：

- `SERVER_HOST`
- `SERVER_PORT`
- `SERVER_USER`
- `SERVER_SSH_KEY`
- `SERVER_HOST_KEY`

服务器由 systemd 运行 Node.js 进程，并通过支持 WebSocket 的 Nginx 反向代理
对外提供游戏。部署脚本会在健康检查失败时自动切回上一个版本。

## 自动化联机检查

```bash
npm run build
npm run test:animation
npm run test:combat
npm run test:smoke
```

动画测试会锁定方块人物/武器分层、连续步态、八向瞄准和枪口几何；战斗几何测试会验证
场景碰撞、可见命中半径和墙体挡弹；联机测试会连接两个玩家并验证随机外观、名字、
僵尸朝向、三把武器和 45 度射击。

## 项目结构

```text
client/  Phaser + TypeScript + Vite 游戏客户端
         其中 block-character.ts 是玩家与僵尸共用的程序化方块模型
shared/  客户端与服务器共用的方向、武器和枪口规则
server/  Express + Socket.IO 权威游戏服务器
scripts/ 本地验证脚本
```

玩家身份目前保存在 `server/data/players.json`。这是适合初版的本地存储；正式上线时可以替换为 Supabase Auth 和 PostgreSQL。

## Unity 客户端迁移

新的 Unity 6.3 LTS 客户端位于 `unity-client/`。Unity 版本采用正交相机下的原创 3D 方块模型，角色保持固定完整层级，武器挂在手部插槽，弹道从武器自身枪口节点生成。

编辑器内按 Play 会进入离线画面预览；WebGL 构建会通过浏览器桥直接连接现有 Socket.IO 服务。运行 `npm run test:unity` 可以检查模型层级、枪口、联机桥、乐观输入和 WebGL 加载器等迁移约束。

`unity-client/PrebuiltWebGL/` 保存经过浏览器验证的 WebGL 发布物；默认 `main` 工作流会用它替换旧客户端、运行联机检查并复用当前 SSH 回滚部署流程。手动工作流 `Deploy EasyGame Unity Preview` 可从 Unity 源码重新构建，启用它还需要配置 `UNITY_LICENSE`、`UNITY_EMAIL` 和 `UNITY_PASSWORD`。
